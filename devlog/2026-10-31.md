## 打包踩的坑（都已修，别重复踩）

1. **冻结后左侧导航空白、右侧全黑**：页面插件由 `app/plugins/__init__.py` 用 `importlib.import_module` 动态加载，PyInstaller 静态分析看不到；`fishdesk.spec` 里必须 `collect_submodules("app")`。
2. **`Could not create temporary directory!`**：onefile 启动要解包到 `%TEMP%`；受限沙箱/企业策略下 `%TEMP%` 不可写就会失败。把 `TEMP`/`TMP` 指到可写目录可复现验证；桌面双击通常不受影响。
3. 单实例要用互斥体 + socket 双保险，且截图/探针脚本不能用 pid 找窗口：onefile 的 loader 是父进程，真正的 Tk 窗口属于子进程。
4. PowerShell 脚本必须存成 UTF-8 **with BOM**，否则 Windows PowerShell 5.1 按 GBK 解析，中文全是乱码。

## 本轮（打包后修复）

- **UI 状态灯误报「微信离线」**：微信 4.x 进程是 `Weixin.exe`、主窗类名 `Qt51514QWindowIcon`（3.x 才是 `WeChat.exe` / `WeChatMainWndForPC`）。改为「窗口类名 + 双进程名」探测，结果缓存 1 秒。
- **UAC 改为按需提权**：spec 里 `uac_admin=False`（asInvoker），只有「保存作息设置」「立即休眠」走 `ShellExecuteW(runas)`；`bootstrap.maybe_elevate` 默认不自提权（开发态需 `FISHDESK_ELEVATE=1`）。
- **黑窗**：所有 `subprocess.Popen`（桥启动、watchdog 拉起、tasklist/powershell 探测）统一 `CREATE_NO_WINDOW` + 隐藏 `STARTUPINFO`。
- **抢焦点/污染剪贴板**：`wxui.py` 发送路径包 `_send_guard()/_send_restore()`——发前记下前台窗口、微信是否最小化、剪贴板全格式快照；发完恢复剪贴板、把前台还回去、原来最小化就再最小化。
- **剪贴板快照本身有 bug**：`GetClipboardData`/`EnumClipboardFormats`/`GlobalSize` 没声明原型，默认 restype 是 C int，64 位下句柄被截断 → 快照永远为空、恢复永远失败。补上原型后实测 4 种格式往返一致。
- **PostMessage 后台发送判定不可行**：微信 4.x 主窗口只有 2 个子窗口（`Qt51514QWindowIcon` + `MMUIRenderSubWindow` 渲染面），没有输入框 HWND；UIA 也枚举不到 Edit 控件。所以只能保留「前置 + 模拟输入」的轻量方案。
- **打包踩坑**：运行中的旧 exe 占着 `dist\XiaoFeiYuConsole.exe`，PyInstaller 会 `PermissionError: WinError 5`；旧实例若是提权启动的，普通权限杀不掉（`taskkill` 也拒绝访问），需用户手动关或换输出目录。
- Git：`git init -b main`（便携版 Git 2.56），80 个文件入库，敏感扫描（wxid/群号/token）已清零后提交；push 需要凭据，`GIT_TERMINAL_PROMPT=0` 下报 `could not read Username`。
